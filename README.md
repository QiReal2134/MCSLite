# ⛏ MCSLite — 轻量 Minecraft 服务器管理面板

参考 MCSManager 设计理念的极简 MC 服务器面板:**零依赖 Node.js 实现,占用极小、启动即用、易于更新**。

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 🎮 玩家界面(默认) | 无需登录,实时查看服务器占用(CPU/内存)、在线玩家、服务器版本、MOTD、IP 地址 |
| 🔐 管理后台 | 输入账号密码进入(参考 MCSM),支持多用户(管理员/操作员) |
| 📦 导入整合包 | 支持浏览器上传 `.zip` / `.tar.gz`,也支持直接填写服务器本地路径导入;自动识别服务端 jar |
| 📁 文件管理 | 目录浏览、上传/下载、在线编辑、重命名、删除、解压 |
| 🎛 可视化配置 | `server.properties` 图形化编辑(开关/下拉/数字),JVM 内存滑块、EULA、自动启动 |
| ☕ 自动寻找 Java | 扫描 `JAVA_HOME`、PATH、常见安装目录、`.minecraft` 运行时,自动选择匹配版本的 Java |
| 🌐 IP 绑定 | 自动检测本机局域网 IP,一键写入 `server-ip` / `server-port`;面板监听地址可配置 |
| 🖼 卡贴式设计 + 毛玻璃 | 玻璃拟态卡片 + 可更换背景,默认使用 `web/bg.jpg` |
| 🛡 安全 | scrypt 密码哈希、HttpOnly 会话、登录限流、路径穿越防护、无 shell 命令注入、CSP 头 |

## 🚀 快速开始

1. 安装 [Node.js](https://nodejs.org) 18+(已安装可跳过)
2. 安装 Java 8 / 17 / 21(运行 MC 服务端需要,面板会自动检测)
3. 双击 **`start.bat`**(或命令行执行 `node server.js`)
4. 浏览器打开 **http://127.0.0.1:8333**(局域网:http://本机IP:8333)
5. 默认账号 **admin / admin123** —— ⚠️ **首次登录请立即修改密码!**

## 📂 目录结构

```
MCSLite/
├── server.js          # 主程序(唯一入口)
├── start.bat          # Windows 一键启动
├── bg.jpg             # 默认背景的根目录副本(面板实际读取 web/bg.jpg)
├── lib/               # 后端模块(路由/认证/实例/Java/探测/文件)
├── web/               # 前端(HTML/CSS/JS,零构建)
├── data/              # 运行时数据:配置、用户、背景(更新时保留)
└── servers/           # 每个服务器实例一个文件夹(更新时保留)
```

## 🎛 使用流程

1. **导入整合包**:管理后台 →「新建 / 导入整合包」→ 上传 `.zip` 或填本机路径 → 面板自动解压并识别服务端 jar
2. **实例设置**:勾选「同意 EULA」、选择内存与 Java 版本(或自动)
3. **启动**:概览页点击 ▶ 启动;控制台可查看日志、发送指令(如 `list`、`op 玩家名`)
4. **绑定 IP**:可视化配置 → 网络与绑定 → `server-ip`(留空=监听所有网卡)、`server-port`
5. **玩家连接**:`http://本机IP:8333` 玩家界面查看状态;游戏内连接 `本机IP:25565`

## 🔄 如何更新

面板数据全部在 `data/` 与 `servers/`,更新时:

1. 停止面板
2. 备份 `data/`、`servers/`
3. 用新版覆盖 `server.js`、`lib/`、`web/`、`start.bat`
4. 重新启动即可,所有配置/实例/日志不丢失

## 🛡 安全说明

- 默认监听 `0.0.0.0:8333`(玩家界面公开只读,管理后台需登录)
- 首次使用**务必修改默认密码**;玩家界面不暴露任何敏感信息
- 密码使用 scrypt + 随机盐哈希存储;登录接口有 60 秒限流
- 文件管理被限制在实例目录内,无法越权访问系统文件
- 背景图/首页图只能指向图片文件,公开的 `/bg`、`/hero` 路由无法被指向敏感文件
- 玩家下载世界存档/备份有每 IP 限速;运行中的服务端打包前会自动 `save-off`/`save-all`
- 所有外部命令通过参数数组调用,杜绝 shell 注入

## ❓ 常见问题

- **启动报错 `未找到 Java`**:在「Java 检测」页扫描,或到 Java 官网安装 JDK 21(兼容 1.20.5+)
- **看不到在线玩家列表**:服务端需开启 `enable-query=true`(可视化配置中勾选)才能显示玩家名字,数量不受影响
- **改端口**:`node server.js --port 9000 --host 0.0.0.0`,或修改 `data/config.json`
- **整合包没有服务端文件**:部分整合包只有客户端文件,请使用服务端版整合包
